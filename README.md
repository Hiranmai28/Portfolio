# Hiranmai Devarasetty — Portfolio

Personal portfolio site showcasing my work at the intersection of data, AI, and applied machine learning. Built as an interactive, Prezi-style single-page experience with animated network visuals and zoom-in section navigation.

**Live site:** [hiranmai28.github.io/Portfolio](https://hiranmai28.github.io/Portfolio/)

## About

I build AI agents, RAG pipelines, ML models, and dashboards that ship to production. This portfolio walks through my career path, projects, technical toolkit, and credentials in one continuous experience.

## Tech Stack

- **Framework:** React (Create React App)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Animations:** Custom CSS keyframes, SVG network background, IntersectionObserver-driven counters

## Features

- Prezi-style zoom-in navigation for each section
- Animated typewriter hero with rotating role titles
- Live counter animations for impact metrics
- Interactive particle and line-network background
- Fully responsive layout

## Local Development

Clone the repo and install dependencies:

```bash
git clone https://github.com/Hiranmai28/Portfolio.git
cd Portfolio
npm install
```

Start the dev server:

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page reloads on changes.

## Build for Production

```bash
npm run build
```

Outputs an optimized bundle to the `build` folder, ready for deployment.

## Deployment

Deployed via GitHub Pages. To redeploy after changes:

```bash
npm run build
npm run deploy
```
